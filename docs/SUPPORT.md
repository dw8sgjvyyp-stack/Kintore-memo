# Muscle Memo サポート

最終更新日: 2026-10-31

Muscle Memo（筋トレMEMO）をご利用いただきありがとうございます。このページでは、基本的な使い方、データのバックアップ、不具合が起きた場合の確認方法をご案内します。

## アプリ概要

Muscle Memoは、ジムでのトレーニングを素早く記録するための個人向けアプリです。

主な機能:

- Push / Pull / Legs / 自作メニューからトレーニング開始
- 重量、回数、RPE、メモの記録
- セット追加、削除、前回コピー
- トレーニング途中保存と続きから再開
- 日付またぎ時の確認
- 履歴、カレンダー、分析
- 体重、睡眠の記録
- JSONバックアップと復元
- 端末内保存

## 基本的な使い方

1. ホームでメニューを選びます。
2. 「トレーニングを開始」を押します。
3. 種目タブを切り替えながら、セットを入力します。
4. 必要に応じて、種目追加、種目変更、スキップを使います。
5. トレーニング終了時に保存すると、履歴、カレンダー、分析へ反映されます。

## 途中保存と再開

トレーニング中の入力内容は、進行中トレーニングとして自動保存されます。アプリを閉じたり別画面へ移動しても、ホームに「進行中のトレーニング」が表示され、続きから再開できます。

不要になった進行中トレーニングは、確認画面から破棄できます。

## データバックアップ

設定画面の「JSONエクスポート」から、現在のデータをJSONファイルとして保存できます。機種変更や安全な控えを作りたい場合は、定期的なエクスポートをおすすめします。

バックアップには、トレーニング記録、体重、睡眠、メニュー、種目、設定、進行中トレーニングが含まれます。

## データ復元

設定画面の「JSONインポート」から、過去にエクスポートしたJSONファイルを読み込めます。

インポート時は確認画面が表示され、現在の保存データを上書きします。復元前に必要なデータをJSONエクスポートしてください。

## 不具合時の対処

- アプリを再起動する
- iOS版の場合は端末を再起動する
- Web/PWA版の場合はブラウザを更新する
- 入力中の記録がある場合は、ホームの「続きから再開」を確認する
- 復元前にJSONバックアップを作成する

端末内データはアプリの削除により失われる場合があります。アプリの再インストール前には、可能な限りJSONバックアップを作成してください。

## 問い合わせ

不具合の報告やご質問は、[GitHub Issues](https://github.com/dw8sgjvyyp-stack/Kintore-memo/issues)からお問い合わせください。

お問い合わせの際は、問題が起きた画面、操作手順、iOSまたはブラウザのバージョンをお知らせください。トレーニング記録、体重、睡眠、バックアップJSONなどの個人データは添付しないでください。
