# Muscle Memo サポート

最終更新日: 2026-08-30

このページは、Muscle Memoのサポートページとして公開するための文案です。公開前に正式な問い合わせ先を設定してください。

## アプリ概要

Muscle Memoは、ジムでのトレーニングを素早く記録するための個人向けアプリです。

主な機能:

- Push / Pull / Legs / 自作メニューからトレーニング開始
- 重量、回数、RPE、メモの記録
- セット追加、削除、前回コピー
- トレーニング途中保存と続きから再開
- 日付またぎ時の確認
- 履歴、カレンダー、分析
- 体重、睡眠の記録
- JSONバックアップと復元
- 任意のFirebase同期

## 基本的な使い方

1. ホームでメニューを選びます。
2. 「トレーニングを開始」を押します。
3. 種目タブを切り替えながら、セットを入力します。
4. 必要に応じて、種目追加、種目変更、スキップを使います。
5. トレーニング終了時に保存すると、履歴、カレンダー、分析へ反映されます。

## 途中保存と再開

トレーニング中の入力内容は、進行中トレーニングとして自動保存されます。アプリを閉じたり別画面へ移動しても、ホームに「進行中のトレーニング」が表示され、続きから再開できます。

不要になった進行中トレーニングは、確認画面から破棄できます。

## データバックアップ

設定画面の「JSONエクスポート」から、現在のデータをJSONファイルとして保存できます。機種変更や安全な控えを作りたい場合は、定期的なエクスポートをおすすめします。

バックアップには、トレーニング記録、体重、睡眠、メニュー、種目、設定、進行中トレーニングが含まれます。

## データ復元

設定画面の「JSONインポート」から、過去にエクスポートしたJSONファイルを読み込めます。

インポート時は確認画面が表示され、現在の保存データを上書きします。復元前に必要なデータをJSONエクスポートしてください。

## Firebase同期

Firebase同期は任意機能です。ユーザーがFirebase設定JSONとFirestoreパスを入力し、同期を有効にした場合のみ動作します。

同期設定を行わない場合、データは端末内に保存されます。

## 不具合時の対処

- アプリを再起動する
- iOS版の場合は端末を再起動する
- Web/PWA版の場合はブラウザを更新する
- 入力中の記録がある場合は、ホームの「続きから再開」を確認する
- 復元前にJSONバックアップを作成する
- Firebase同期を使っている場合は、設定JSONとFirestoreパスを確認する
