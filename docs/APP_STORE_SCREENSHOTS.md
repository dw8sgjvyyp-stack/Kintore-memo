# App Store スクリーンショット候補

最終更新日: 2026-08-30

今回は画像加工は行わず、撮影すべき画面候補を整理します。iPhone向けにPortraitで撮影する方針です。

## 候補1. ホーム / トレーニング開始

見せる内容:

- 今日の日付
- おすすめメニュー
- Push / Pull / Legs / 自作メニュー
- トレーニング開始ボタン
- 進行中トレーニングがある場合の再開カード

狙い:

アプリを開いてすぐトレーニングを始められることを伝える。

## 候補2. トレーニング記録

見せる内容:

- トレーニング中の種目タブ
- 現在種目カード
- 前回記録
- セット一覧
- 休憩タイマー

狙い:

ジムで片手操作しやすい記録画面を見せる。

## 候補3. セット入力Bottom Sheet

見せる内容:

- 重量と回数の大きな入力
- クイック調整ボタン
- RPE選択
- メモ
- このセットを保存ボタン

狙い:

素早くセット入力できることを伝える。

## 候補4. 履歴カレンダー

見せる内容:

- 記録日の赤い点
- 選択日の記録一覧
- メニュー名、合計セット、総重量

狙い:

いつトレーニングしたかを振り返りやすいことを示す。

## 候補5. 履歴詳細

見せる内容:

- 1日の合計カード
- 種目ごとのセット内容
- 重量、回数、完了チェック

狙い:

過去の内容を具体的に確認できることを見せる。

## 候補6. 体重グラフ

見せる内容:

- 最新体重
- 前回比
- 週 / 月 / 3ヶ月 / 年
- 折れ線グラフ
- 平均 / 最高 / 最低

狙い:

トレーニング以外の体調変化も記録できることを伝える。

## 候補7. トレーニング分析

見せる内容:

- 今月の総重量
- セット数、レップ数
- 総重量推移
- メニュー別割合
- PRカード

狙い:

成長やトレーニング量を簡単に振り返れることを示す。

## 撮影メモ

- 5から7枚を推奨
- 記録が少ない空状態ではなく、デモデータありの状態で撮影する
- 個人情報や実際のFirebase設定JSONを映さない
- JSONバックアップ画面を撮る場合、ファイル名や設定値に注意する
- App Store Connect登録前に、対象ディスプレイサイズの最新仕様を確認する
