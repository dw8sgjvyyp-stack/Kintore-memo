## 説明文案

筋トレMEMOは、ジムでの記録を素早く続けるためのトレーニング記録アプリです。

重量、回数、RPE、メモをコンパクトに入力でき、セット数は自由に追加・削除できます。前回記録のコピー、セット数だけコピー、空で開始など、トレーニング中の状況に合わせて使えます。

Push / Pull / Legs / 自作メニューに対応し、種目は胸、背中、肩、腕、脚、腹などの部位ごとに整理できます。記録中でも種目追加、種目変更、スキップができるため、ジムで予定が変わっても記録を止めずに続けられます。

トレーニング途中でアプリを閉じても、進行中トレーニングとして保存され、あとから続きから再開できます。日付を跨いだ場合は、前日の記録として保存するか、今日の新しいトレーニングを始めるかを選べます。

履歴、カレンダー、分析画面では、いつ何をどれだけ行ったかを見返せます。体重と睡眠も個別に記録でき、トレーニング量とあわせて振り返れます。

データは基本的に端末内に保存されます。JSONバックアップと復元に対応し、任意でFirebase同期も設定できます。

現在のXcodeプロジェクトには、Capacitor生成時の1024x1024 PNGが入っています。形式上は正方形、アルファなしです。

正式提出前に、以下の条件を満たす筋トレMEMO用アイコンへ差し替えてください。
